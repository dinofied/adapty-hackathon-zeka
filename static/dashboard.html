      How a referral works

      1. The user taps Refer a friend; the phone’s share sheet sends their link.
      2. The link is an Adapty Attribution link carrying the code in deferred_data_sub1.
      3. The friend installs; on first launch the Adapty SDK returns the payload (onInstallationDetailsSuccess) and the app claims the code.
      4. Your rules run: access levels are granted and attributes are written to both profiles.
      5. Segments on those attributes route each user to the right paywall.
      Adapty custom attributes hold up to 50 characters each, 30 per profile. The full invite graph stays in the referral service; profiles get counts, tiers and flags.
